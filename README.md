# COPAG — Business Intelligence & Commercial Performance Analysis

## 📌 Project Overview

This project focuses on designing and implementing a **Business Intelligence (BI) solution** to centralize, process, and analyze commercial data, enabling better performance monitoring and data-driven decision-making.

The solution follows a business intelligence architecture that integrates a Data Lake, a Data Warehouse, ETL processes, an analytical layer, and interactive Power BI dashboards.

## 🎯 Project Objectives

- Centralize data from operational systems.
- Design a Data Warehouse for multidimensional analysis.
- Automate data integration and transformation processes.
- Analyze commercial performance across multiple dimensions.
- Monitor sales performance and key performance indicators (KPIs).
- Present analytical insights through Power BI dashboards.

## 🏗️ Project Architecture

The solution is organized into the following components:

1. **Data Lake** — Centralizes data from source systems.
2. **ETL Processes (SSIS)** — Extracts, transforms, and loads data into the Data Warehouse.
3. **Data Warehouse** — Structures data using a Snowflake Schema to support analytical queries.
4. **Multidimensional Analysis (SSAS)** — Provides an analytical layer for exploring business data.
5. **Data Visualization (Power BI)** — Presents key indicators through interactive dashboards.

## 📊 Business Analysis

The solution supports commercial performance analysis across several dimensions:

- **Products and Items:** Analysis of sales quantities and product performance.
- **Agencies:** Comparison of commercial performance across agencies.
- **Sectors:** Monitoring performance by business sector.
- **Time Periods:** Analysis of changes in performance over time.

### Key Performance Indicators (KPIs)

The project focuses on the following indicators:

- Tonnage
- Revenue
- Sales
- Unsold quantities
- Losses

These indicators help identify business trends and provide a clearer understanding of commercial performance.

## 📈 Expected Benefits

The solution aims to:

- Reduce commercial data fragmentation.
- Improve access to key performance indicators.
- Accelerate data analysis and reporting.
- Provide better visibility into commercial performance.
- Support decision-making through structured analytical data.
